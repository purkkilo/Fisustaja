# client

Vue 3.5 + Vuetify 4 + Vite. State lives in Pinia, routing in Vue Router 5, translations in vue-i18n 11.

Needs Node.js 20.19+ or 22.12+.

## Project setup

```
npm install
```

### Dev server with hot reload (proxies /api to the Express server on port 5000)

```
npm run dev
```

### Build for production (outputs to ../server/public)

```
npm run build
```

### Lint (also flags leftover Vuetify 2/3 props and classes)

```
npm run lint
```

See the [Vite config reference](https://vite.dev/config/) and the
[Vuetify docs](https://vuetifyjs.com/).
